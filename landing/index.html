The Anti-Algorithm Manifesto

Designed to ground your attention, not capture it.

Most software fights for your dopamine. Daily Sutra is a digital shrine: calm, quiet, mathematically certain, and gone the moment you click away.

🔢

Deterministic Calendar Math

No AI recommendations, no feeds, and no engagement tracking. A date-seeded shuffle picks the verse for each day, so every verse appears once per 42-day cycle. Within an app version, the same calendar date always gives the same verse, anywhere, and tomorrow brings the next with gentle inevitability.

Getting Started

Install Daily Sutra in seconds.

  • 1

    1. Download Release

    Download DailySutra.zip from the official GitHub Release (v1.1.4).

    DailySutra.zip (1.8 MB)
  • 2

    2. Move to Applications

    Unzip the archive and drag DailySutra.app into your /Applications folder.

  • 3

    3. Open & Contemplate

    Click the lotus icon in your menu bar. The verse panel opens instantly.

macOS Gatekeeper Note

Daily Sutra is an open-source indie app. Because it is distributed outside the Mac App Store without an Apple Developer ID signature, macOS may display an unidentified developer warning on first launch. Simply right-click DailySutra.app and select Open, or run:

xattr -dr com.apple.quarantine /Applications/DailySutra.app

Homebrew Cask

Install in one command. The cask clears the Gatekeeper quarantine flag for you:

brew install --cask acchuang/tap/daily-sutra

Build From Source

Pure Swift Package Manager — no Xcode project file required:

git clone https://github.com/acchuang/daily-sutra.git
cd daily-sutra && ./build.sh
open build/DailySutra.app
Questions & Answers

Frequently Asked Questions

Daily Sutra contains 42 contemplative passages: all 32 chapters of the Diamond Sutra (金剛般若波羅蜜經, Kumārajīva text) and 10 contemplative verses from the Heart Sutra (般若波羅蜜多心經, Xuanzang text). The app unifies them into a single pool without announcing which sutra a verse belongs to, keeping your focus on contemplation rather than cataloging.
None whatsoever. Daily Sutra is completely offline. The entire verse database is bundled within the app. There are no tracking libraries, no Google Analytics, no external API calls, and no accounts required.
Every day at midnight, the app re-rolls using a deterministic date-seeded shuffle: every verse appears once per 42-day cycle, in an order fixed by the cycle number. Within an app version, the same calendar date gives the same verse anywhere in the world (the date is read in your local time zone), without needing an internet connection or server.
Yes! Open Settings (Cmd+,) and enable Daily Notification at your preferred morning hour (e.g., 08:00 AM). Clicking the notification immediately reveals the morning verse.
Yes. The paraphrases, explanations, reflections and blessings were drafted with AI assistance, then reviewed and edited by the author; much of the code was too. They are interpretations, not the canonical sutra text. The bundled Chinese and English sutra texts are public domain (English: Gemmell 1912 for the Diamond Sutra, Max Müller 1894 for the Heart Sutra; Müller translated the Sanskrit, so it differs from Xuanzang's Chinese in places).
